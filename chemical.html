Types of Chemical Reaction

1.Combination Reaction

Definition :---
A combination reaction is a chemical process where two or more simple substances join together to create one single, new product.

General form :- (A + B ---- AB).

Example:-

  • Formation of water :- 2H2 (g) + O2 (g) ----- 2H2O (l).
  • Burning of Coal :- C (s) + O2 (g) ----- CO2 (g).
  • Formation of slaked Lime :- CaO + H2O ----- Ca(OH)2 .

2.Decomposition Reaction

Definition :---
A decomposition reaction is a chemical process where a single complex compound breaks down into two or more simpler substances or elements.

General Form :- AB ---- A + B.

Type of Decomposition Reaction:-

  • Thermal Decomposition:- Uses heat to break down a substance.
    Example :- CaCO3 (s) ----- CaO (s) + CO2 (g).
  • Electrolytic Decomposition:- Uses electricity to split a compound.
    Example :- 2H20 (l) ----- 2H2 (g) + O2 (g).
  • Photolytic Decomposition:- Uses light energy to decompose a substance.
    2AgCl (s) ---- 2Ag + Cl2.    .

3.Displacement Reaction

Definition :---
A displacement reaction is a chemical change where a more reactive element takes the place of a less reactive element inside a compound.

General Form :- A + BC ---- AC + B.

Example :-

  • Iron and Copper Sulfate :- Fe + CuSO4----FeSO4 + Cu
  • Zinc and Hydrochloric Acid :- Zn + 2HCl ----- ZnCl2 + H2

4.Double Displacement Reaction

Definition :---
A double displacement reaction is a chemical change where two reactant compounds swap their positive and negative ions to create two brand-new products.

General Form :- AB + CD ---- AD + CB.

Example :-

  • Precipitation Reaction :- Mixing two clear liquids forms an insoluble solid.
    Example :- Na2SO4 + BaCl2 ----- BaSO4 + 2NaCl.
  • Neutralisation Reaction :- An acid and a base react to form salt and water.
    Example :- HCl + NaOH ----- NaCl + H2O

5.Combustion Reaction

Definition :---
A combustion reaction is a high-energy chemical process where a fuel substance reacts with oxygen gas.

General Form :- Cx Hy + (x + y/4)O2 ---- xCO2 + y/2 H2O + Heat/Light.

Example :-

  • Complete Combustion :- CH4 + 2O2 ----- CO2 + 2H2O + Heat.
  • Incomplete Combustion :- 2CH4 + 3O2 ----- 2CO + 4H2O + Heat.

6.Neutralization Reaction

Definition :-
A neutralization reaction is a chemical process where an acid and a base mix and react with each other.

General Form :- H+ (aq) + OH- (aq) ---- H2O (l).

Example :-

  • Table Salt Formation :- HCl + NaOH ----- NaCl + H2O.
  • Stomach Antacid :- Mg(OH)2 + 2HCl ----- MgCl2 + 2H2O.
